# МК — сайт автомойки в Актобе

Готовый одностраничный сайт, который открывается прямо из `index.html`, без установки.

## Что внутри
- современный адаптивный дизайн под автомойку;
- первый экран с CTA;
- услуги и цены в тенге;
- преимущества;
- отзывы;
- FAQ;
- контакты, телефон, WhatsApp и карта;
- форма заявки: имя + телефон;
- панель владельца через `#admin`;
- новые заявки появляются в панели без перезагрузки;
- экспорт заявок в CSV;
- сохранение заявок в localStorage.

## Панель владельца
На сайте нажмите «Панель владельца».
PIN по умолчанию: `2468`.

## Важно для запуска бизнеса
Эта готовая файловая версия работает без сервера и сохраняет заявки в браузере. Для полноценной онлайн-версии, где заявки будут приходить владельцу с любых телефонов и компьютеров в единую базу, нужен небольшой сервер/облачная база (например, Supabase/Firebase или API сайта). В текущей версии обмен «без перезагрузки» работает между вкладками одного браузера.
